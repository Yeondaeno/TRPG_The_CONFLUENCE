## affordances — 자유 행동 파서(B)가 쓸 데이터

**모든 씬에** 답니다. 이게 룰북 1.4의 '창의적 행동'을 살리는 재료입니다.

```jsonc
"affordances": [
  { "id": "streetlamp",
    "noun": ["가로등", "등불", "조명", "배선", "전선"],
    "tags": ["전기", "결계", "높은곳", "금속"],
    "hint": "골목 위로 낡은 결계 가로등이 늘어서 있다" }
]
```

- `noun` — 플레이어가 부를 법한 **모든 말**을 넣으세요. 조사는 파서가 뗍니다.
- `tags` — 아래 목록에서만 고르세요. 새 태그를 만들면 파서가 모릅니다.

**허용 태그**: `전기` `가연성` `물` `무거움` `날카로움` `금속` `유리`
`결계` `이형` `기계` `높은곳` `좁은곳` `어둠` `소음원` `생명`

- 씬마다 **3~6개**가 적당합니다. 무대에 실제로 있는 것만 — 없는 걸 넣으면
  플레이어가 시도했다가 배신당합니다.
- `hint`는 그 요소가 있다는 걸 내러티브가 이미 말하고 있는지 확인하는 용도입니다.
  **내러티브에 언급되지 않은 affordance를 넣지 마세요.**

# B. 8인 파티 선택 + 자유 행동 파서

## B-1. 8인 파티 선택

지금은 "파티 = 16명 전원"이라 `requires.partyHasSkill`이 아무것도 못 거릅니다
([ADR-002](../adr/002-playable-game.md) 참고).

- 플레이 시작 전에 **16종 중 8명을 고르는 화면**
- 그중 **1명을 "내 캐릭터"** 로 지정 (혼자 플레이 시)
- 여럿이 플레이하면 각자 하나씩 점유 — 기존 `claims`를 그대로 씁니다
- 파티 구성은 `hg:{code}:party`에 저장
- **추천 구성 버튼**: 역할이 겹치지 않게 8명을 자동으로 고릅니다
  (`role` 필드로 전투/지원/기술/사교가 골고루 들어가게)
- `game.js`가 party를 이 8명으로 받게 바꾸세요

## B-2. 자유 행동 파서 (`parser.js`) — 2층

플레이 화면에 **자유 입력창**을 두고, 씬의 affordances와 맞춰봅니다.

```js
const Parser = (() => {
  return {
    // "가로등 배선을 끊어서 감전시킬래"
    //  → { affordance, verb, skill, dc, confidence, reason }
    //  → 못 찾으면 { confidence: 0 } — 막지 말고 수동 선택으로 넘긴다
    interpret(text, scene, party) {},
    verbs(),   // 동사 사전
  };
})();
```

### 동사 × 태그 → 판정 규칙표

`data/rules.json`에 넣지 마세요 — 게임 규칙이 아니라 파서의 사전입니다.
`parser.js` 안에 상수로 두거나 별도 `data/parser-verbs.json`으로 빼세요.

| 동사(대표형) | 태그 | 기술 | DC | 결과 성격 |
|---|---|---|---|---|
| 끊다·자르다·부수다 | 전기 | tinker | 15 | 인접 대상 감전 |
| 끊다·부수다 | 결계 | tinker | 15 | 결계 해제, 소음 |
| 태우다·불붙이다 | 가연성 | tinker | 12 | 화재, 시야 차단 |
| 정화하다·쫓다 | 이형 | exorcise | 12 | 잔향 감소 |
| 밀다·던지다 | 무거움 | melee(STR) | 12 | 피해 + 넘어뜨림 |
| 숨다·가리다 | 어둠·좁은곳 | stealth | 12 | 은신 |
| 오르다 | 높은곳 | stealth(AGI) | 12 | 위치 확보 |
| 살피다·조사하다 | (아무거나) | survival | 12 | 정보 |

**표는 시작점입니다.** 태그 15개 × 동사 10여 개 전부를 채울 필요는 없고,
매칭 안 되는 조합은 "그 조합으로는 특별한 효과가 없습니다 — 판정은
해드립니다"로 떨어지면 됩니다.

### 한국어 처리

형태소 분석기를 넣지 마세요(용량). 이 정도면 충분합니다:

- 조사 제거: `을 를 이 가 은 는 에 에서 으로 로 와 과 의 도 만`
- 어미 정규화: `끊어서/끊고/끊는다/끊을래/끊자` → `끊`
  (동사 사전에 어간을 두고 `startsWith`로 매칭)
- 띄어쓰기 무시하고도 한 번 더 시도

### 반드시 지킬 것

**매칭 실패는 정상 경로입니다.** 룰북 1.4의 두 번째 예시("요괴에게 빌린
부적을 도박에 건다")는 장면 요소의 조합이 아니라 서사적 도박이라
**원리적으로 파서가 못 합니다.** 그때:

```
이 장면의 요소로는 해석할 수 없습니다.
룰북 1.4대로 직접 정해 주세요:
  기술 [교역 ▾]  DC [보통 12 ▾]   [판정]
→ 판정은 해드립니다. 결과 서술은 직접 하세요.
```

**"할 수 없습니다"로 막지 마세요.** 판정은 반드시 해줍니다 — 룰북이
"실패해도 이야기가 멈추면 안 된다"고 한 정신입니다.

**해석 결과를 그대로 실행하지 마세요.** 항상 사람이 확인합니다:

```
대상: 가로등 (전기·결계·금속)
행동: 끊다 → 결계 해석 · INT · DC 15
[이대로 판정]  [기술 바꾸기 ▾]  [DC 바꾸기 ▾]  [취소]
```

**자유 행동은 `usedChoices`에 걸리지 않습니다** — 미리 쓰인 선택지가 아니라
매번 새로운 시도이므로. 대신 같은 affordance를 반복 착취하지 못하게
**affordance당 1회**로 제한하세요.
