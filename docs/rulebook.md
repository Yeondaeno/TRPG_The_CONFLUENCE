> 차원 융합 어반판타지 TRPG
> 8인 이상 파티 · 사람 GM 진행 · 원샷 3~4시간

## 0. 이 세계는 무엇인가

어느 날 원인 불명의 '융합 현상'이 일어나 지구의 차원이 전혀 다른 성질을 가진 이계(異界)들과 뒤섞였습니다. 그 결과 하나의 거대도시 **합경(合境, Confluence)** 이 태어났습니다. 이 도시는 구역마다 완전히 다른 세계의 법칙이 흐릅니다 — 동양 요괴가 거니는 골목, 네온이 흐르는 사이버펑크 지구, 숲이 건물을 삼킨 자연 지구, 금지된 의식이 벌어지는 오컬트 회랑, 뱀파이어와 헌터가 대치하는 고딕 지구, 기사단이 법을 세운 기사령, 마법과 기계가 뒤엉킨 마공학 단지까지. 「합경」은 이 뒤섞인 도시에서 살아가는 이들의 이야기를 만드는 TRPG입니다.

규칙 골격은 d20 기반 판정과 전투를 갖추되, 규칙서에 없는 상황도 GM이 즉시 판정할 수 있는 **범용 판정 프레임워크**를 핵심으로 합니다. GM 1명 + 플레이어 8명 이상의 대규모 파티, 여러 구역을 병렬로 오가는 진행을 전제로 설계되었습니다.

## 1. 핵심 판정 시스템

### 1.1 기본 굴림

```
d20 + 능력치 보정 + (숙련 시 +2) ≥ DC(난이도)
```

d20을 굴려 나온 숫자에 관련 능력치 보정치를 더하고, 캐릭터가 해당 기술에 숙련되어 있다면 +2를 추가합니다. 합계가 GM이 정한 DC 이상이면 성공입니다.

### 1.2 능력치 (6종)

| 능력치 | 약자 | 다루는 것 |
|---|---|---|
| 근력 | STR | 근접 공격, 무거운 것 옮기기, 강제로 부수기 |
| 민첩 | AGI | 사격, 회피, 은신, 반응속도, 선제권 |
| 지구력 | CON | 체력, 차원 여파 저항, 피로/저주 저항 |
| 지능 | INT | 마도구 정비, 결계 해석/시스템 해킹, 의식/주술 지식 |
| 감각 | WIS | 관찰, 생존술, 직감, 기척 추적 |
| 매력 | CHA | 설득, 협박, 교역, 리더십, 사교계 처세 |

능력치 보정치는 -1부터 +3까지이며, 기성복 캐릭터시트에 이미 계산되어 있습니다. 캐릭터를 직접 만들고 싶다면 [부록 A](#부록-a-캐릭터-직접-만들기-간이-규칙)를 참고하세요.

### 1.3 난이도(DC) 기준표

| 난이도 | DC | 예시 |
|---|---|---|
| 쉬움 | 8 | 잠기지 않은 문 열기, 뻔한 사실 떠올리기 |
| 보통 | 12 | 낡은 결계 자물쇠 풀기, 낯선 이 설득하기 |
| 어려움 | 15 | 움직이는 표적 저격, 폭주하는 술식 해체 |
| 매우 어려움 | 18 | 무너지는 건물에서 동료 구조, 다중 결계 동시 해킹 |
| 거의 불가능 | 22 | 맨몸으로 상급 이형체 제압, 폭주하는 역참 코어 즉석 안정화 |

### 1.4 결과의 4단계 — '창의적 행동'을 처리하는 방법

플레이어는 규칙서에 없는 행동을 시도할 수 있습니다(예: '가로등의 결계 배선을 끊어 적을 감전시킨다', '요괴에게 빌린 부적을 도박에 건다'). 아래 3단계 절차로 어떤 행동이든 그 자리에서 공정하게 판정하세요.

**절차 1 — 능력치/기술 매칭**
가장 가까운 능력치 하나(필요하면 기술 하나)를 고릅니다. 힘으로 밀어붙이면 STR, 몰래 처리하면 AGI, 말로 풀면 CHA. 정답은 없습니다 — 5초 안에 골라 진행 속도를 지키세요.

**절차 2 — DC 선언**
위 DC표를 기준으로 난이도를 소리 내어 선언합니다. 캐릭터의 장비·소속 구역·상황이 유리하면 DC를 2~4 낮추고, 불리하면 2~4 높이세요.

**절차 3 — 결과를 4단계로 해석**

| 결과 | 조건 | 처리 방식 |
|---|---|---|
| 대성공 | 자연 20 또는 DC+10 이상 | 의도한 대로 완벽하게, 부가 이득 하나 추가 |
| 성공 | DC 이상 | 의도한 대로 이루어짐 |
| 부분 성공 | DC-1 ~ DC-4 | 원하는 걸 얻지만 대가가 따름 (소음, 부상, 자원 소모, 여파 획득 등) |
| 실패 | DC-5 이하 또는 자연 1 | 원하는 걸 얻지 못하고 상황이 악화됨 |

> **핵심 원칙:** 실패해도 이야기가 멈추면 안 됩니다. 항상 '아니오, 그런데' 또는 '예, 하지만'으로 다음 상황을 열어주세요. 설정상 말이 안 되는 행동(예: 맨손으로 벽을 순간이동해 통과)은 판정 없이 안 된다고 말해도 됩니다 — 실패가 아니라 세계관 보호입니다.

### 1.5 그룹 판정 (8인 파티용)

- 절반 이상이 성공하면 전체가 '성공'으로, 절반 미만이면 전체가 '부분 성공'으로 처리합니다.
- 한 명이 '조력자'로 나서면(먼저 관련 기술로 보통 DC 판정) 성공 시 나머지 인원 전원이 +2 보너스를 받습니다.
- 파티가 서로 다른 구역으로 나뉘면 GM이 그룹별로 번갈아 장면을 전환하며(교차 편집) 각 그룹에 1~2분씩 스포트라이트를 줍니다.

### 1.6 기술 목록 (참고용)

아래는 캐릭터시트에 등장하는 기술과 관련 능력치 참고표입니다. 표에 없는 기술을 캐릭터가 시도하면 1.4의 절차로 그 자리에서 새로 정의하세요.

| 기술 | 관련 능력치 | 쓰임 |
|---|---|---|
| 근접전투 / 결투 | STR | 칼과 주먹이 오가는 정면 승부 |
| 사격 | AGI | 총기·석궁 등 원거리 무기 |
| 은신 / 손재주 | AGI | 숨기, 잠그기, 몰래 처리하기 |
| 위협 / 협박 | STR 또는 CHA | 힘 또는 기세로 상대를 굴복시키기 |
| 매혹 / 설득 | CHA | 말과 매력으로 마음을 움직이기 |
| 교역 | CHA | 값을 매기고 흥정하기 |
| 치유술 | INT 또는 WIS | 부상과 상태이상을 다스리기 |
| 정령술 / 저주술 | INT 또는 WIS | 정령과의 교감, 금지된 술식 시전 |
| 퇴마술 | WIS | 이형체·요괴를 가려내고 정화하기 |
| 마도구 정비 / 결계 해석 | INT | 기계와 마법이 뒤섞인 장치 다루기 |
| 생존술 / 추적·관찰 | WIS | 흔적을 읽고 위험을 먼저 감지하기 |
| 동물 교감 | WIS | 동물·정령체와 의사소통하기 |
| 지식 | INT | 역사, 금기, 구역 사정에 대한 앎 |

## 2. 전투 규칙

### 2.1 전투 순서

1. **선제권**: 전원 d20 + AGI 보정 굴림, 높은 순서대로 행동.
2. 각자의 턴에 **주행동 1회 + 이동 1회 + 반응행동 1회(상황 발생 시)** 를 사용.
3. 모든 참가자가 한 번씩 행동하면 라운드 종료, 다시 1번부터.

### 2.2 공격과 피해

**공격 판정**: `d20 + 무기 관련 능력치 보정 + (숙련 시 +2) ≥ 상대 방어치(AC)`.
성공하면 무기 피해 주사위만큼 피해를 입힙니다.

| 무기 유형 | 피해 주사위 | 관련 능력치 |
|---|---|---|
| 맨손 / 둔기 | 1d4 | STR |
| 룬각인 검·창 등 근접 무기 | 1d6 | STR |
| 권총형 결정탄 무기 | 1d6 | AGI |
| 장거리 결정탄/레일건 | 1d8 | AGI |
| 산탄형 결계포 (근거리 한정) | 2d6 | AGI |
| 즉석 룬폭탄 / 술식 | 2d8 (범위) | INT 또는 AGI |

### 2.3 체력과 부상 단계

HP가 0이 되면 '빈사' 상태가 되며, 다른 캐릭터가 응급처치(치유술 DC 12)를 하지 않으면 매 라운드 종료 시 사망 판정(d20, 10 미만 시 사망)을 굴립니다.

| 부상 단계 | HP 비율 | 효과 |
|---|---|---|
| 경상 | 50% 이상 | 페널티 없음 |
| 중상 | 50% 미만 | 모든 판정에 -2, 이동거리 절반 |
| 빈사 | 0 | 행동 불가, 매 라운드 사망 판정 |

## 3. 위상잔향과 여파화

### 3.1 위상잔향 수치

이 세계에서 방사능에 해당하는 것은 **위상잔향(位相殘響)** 입니다. 서로 다른 차원의 경계를 넘나들거나, 불안정한 균열/술식에 노출되거나, 이형체와 접촉하면 잔향이 쌓입니다. 캐릭터는 0~100의 위상잔향 수치를 가지며, 장면당 GM이 정한 만큼(보통 1d6~2d6) 증가합니다.

| 임계치 | 효과 |
|---|---|
| 25 이상 | 모든 신체 능력치 판정에 -1 |
| 50 이상 | -2 페널티, 매 장시간 휴식마다 여파화 판정(d20) |
| 75 이상 | -3 페널티, 최대 HP -25% |
| 100 | 즉시 여파화 표를 굴려 강제 변용 또는 위상 붕괴로 행동불능 |

위상 필터(아이템)를 사용하거나 자신에게 맞는 구역에서 장시간 휴식하면 잔향 수치를 낮출 수 있습니다(1d10 감소).

### 3.2 여파화 표 (d10)

| d10 | 여파 |
|---|---|
| 1 | 재생의 인장 — 장시간 휴식 시 HP 완전 회복 (긍정) |
| 2 | 야조(夜鳥)의 눈 — 어둠 속 판정 페널티 없음 (긍정) |
| 3 | 결정 폐 — 잔향/저주 판정에 +2 (긍정) |
| 4 | 비늘 피부 — 근접 피해 1 감소, 매력 판정 -1 (중립) |
| 5 | 떨리는 손 — 사격 판정 -1, 근접 판정 +1 (중립) |
| 6 | 과민 감각 — 선제권 +2, 최대 HP -2 (중립) |
| 7 | 홍채 변색 — 순수 외형 변화, 효과 없음 |
| 8 | 환청 발작 — 은신 판정에 불리 (부정) |
| 9 | 근육 위축 — STR 판정 -2 (부정) |
| 10 | GM 재량 — 캐릭터가 머물던 구역 테마에 맞는 독특한 여파 창작 |

## 4. 장비, 자원, 조합

### 4.1 결정편(結晶片)

이 세계의 화폐는 **결정편**입니다 — 융합 현상 당시 응축된 차원의 파편으로, 마법 의식에도 기계 부품에도 함께 쓰입니다. 교역, 수리, 제작에 사용되며 각 캐릭터시트에 시작 수치가 있습니다.

### 4.2 즉석 조합

현장에서 주운 재료로 아이템을 만들 수 있습니다: 결정편 소모 + INT(마도구 정비/술식) 판정. 성공 시 아래 표 참고, 실패 시 결정편만 소모됩니다.

| 제작물 | 필요 결정편 | DC | 효과 |
|---|---|---|---|
| 즉석 결정 붕대 | 1 | 8 | HP 1d6 회복 |
| 즉석 룬폭탄 | 3 | 13 | 2d8 범위 피해 |
| 위상 필터 | 2 | 10 | 잔향 1d10 감소 |
| 무기 룬각인 | 3 | 14 | 선택 무기 피해 주사위 1단계 상승 |
| 방어 결계 강화 | 2 | 12 | AC +1 (다음 전투까지) |

## 5. 합경의 구역들

GM은 아래 구역 성향을 참고해 장면의 색을 입히세요. 시나리오 하나에 전부 등장할 필요는 없습니다.

| 구역 | 테마 | 분위기 힌트 |
|---|---|---|
| 무영가(無影街) | 동양 요괴 골목 | 등불, 여우불, 옛 신사, 말수 적은 요괴 상인 |
| 강선지구(鋼線地区) | 사이버펑크 | 네온, 기업 보안, 해커, 인공보철 |
| 푸른뿌리 | 자연 친화 | 건물을 삼킨 숲, 정령, 소리 없는 경고 |
| 심야회랑 | 오컬트 | 금지 의식, 지하 서점, 대가를 요구하는 거래 |
| 재의문 | 고딕 (뱀파이어·헌터) | 안개, 오래된 저택, 밤의 규율 |
| 백기사령 | 기사의 도시 | 성문, 서약, 결투로 해결되는 분쟁 |
| 마공단지 | 마공학 도시 | 마법으로 돌아가는 공장, 폭주 위험, 발명가 |

> 사전 제작 캐릭터 2명(노아·유나)이 소속된 **교환장**은 이 표에 없습니다. [`errata.md` R-1](errata.md#r-1-교환장-구역-정의-누락) 참고.

## 6. GM을 위한 조언

- 8인 이상 파티는 순서대로 다 물어보면 늘어집니다 — 구역이 갈리면 '지금 이 그룹', '저 그룹은 잠시 대기'로 명확히 전환하세요.
- 판정은 '결과가 이야기를 바꿀 때만' 요구하세요. 뻔한 일은 그냥 성공시키는 게 진행이 빠릅니다.
- 3~4시간 원샷은 시간이 생명입니다 — 시나리오 문서의 Act별 목표 소요시간을 참고해 페이스를 조절하세요.
- 플레이어가 규칙에 없는 걸 시도하면 1.4의 3단계를 쓰세요.
- 몬스터/NPC 스탯과 시나리오 진행은 「합경 — 시나리오: 역참-0」 문서를 참고하세요.

> 「합경 — 시나리오: 역참-0」 문서는 이 저장소에 아직 없습니다. [`errata.md` R-6](errata.md#r-6-시나리오-역참-0-문서-부재) 참고.

## 부록 A. 캐릭터 직접 만들기 (간이 규칙)
